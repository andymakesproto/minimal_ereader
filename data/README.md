# Sample books

This folder contains sample `.txt` books that can be uploaded to the device using PlatformIO's **Upload Filesystem Image** task. To add books this way, place them in this folder, then follow the alternative instructions in the root README.

This method is mainly intended for firmware development. For everyday use, transfer books over Wi-Fi instead.

**Warning:** Uploading a filesystem image replaces the files already stored on the device, including books and reading progress. Use Wi-Fi Transfer if you want to add books without replacing existing files.
